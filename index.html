Not everything is a list. When a slide needs a diagram that animates, write it as an HTML section next to the Markdown and register its walkthrough with Deck.steps. It takes part in the same navigation as everything else: the down arrow, the step counter, the URL. In read view a hand-built slide appears as a figure with a Present button, or reflows if you mark it as flow.
